Para onde vai o seu apoio

Quanto apoiar?

O valor é seu. Para ter uma ideia: um cafezinho já paga uma boa parte do trabalho de revisar e testar um guia, e é bem menos do que o tempo que uma ferramenta pronta costuma poupar. Qualquer valor é recebido com gratidão.

Como apoiar com Pix

  1. Abra o aplicativo do seu banco e escolha Pix.
  2. Selecione Pagar com QR Code e aponte a câmera para o QR Code desta página.
  3. Digite o valor que quiser e confirme.
  4. Está no celular? Tire um print do QR Code e, no app do banco, procure a opção de ler a partir de uma imagem da galeria (a maioria dos bancos tem).
