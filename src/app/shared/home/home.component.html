Geradores de documentos e dados de teste para desenvolvedores

O 4DevTools gera CPF, CNPJ (inclusive alfanumérico), CNH, PIS, RENAVAM e outros dados brasileiros fictícios para testar sistemas sem usar informações de pessoas reais. Cada gerador explica como o número é formado e traz funções de validação prontas em TypeScript, Python, C# e Java.

Como os dados são gerados

  • No seu navegador: os números são calculados no próprio navegador, com os mesmos algoritmos de dígito verificador usados pelos órgãos emissores. Os dados gerados não são enviados nem guardados pelo 4DevTools.
  • Válidos, mas fictícios: os números passam nas validações de formato, mas não são consultados em nenhuma base. Podem coincidir com documentos reais, por isso devem ser usados só em testes.
  • Testados: os geradores e as funções de validação publicadas são conferidos contra milhares de casos e contra bibliotecas de referência.

Use os dados gerados apenas para desenvolvimento e testes de software. Usar números de documentos para se passar por outra pessoa ou empresa é crime.

Quem faz o 4DevTools

O 4DevTools é mantido por Fernando Parmezani, desenvolvedor, para ajudar quem desenvolve e testa sistemas no Brasil. Encontrou um erro ou quer sugerir uma ferramenta? Fale com a gente pela página de contato.
